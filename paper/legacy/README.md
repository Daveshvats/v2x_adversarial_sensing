# paper/legacy/ — the unpublished ICE2CT-2026 manuscript

**Status: unpublished preprint.** This manuscript — *Dual-Stream
Phase-Aware Inception-Time CNN for Adversarially Robust Spectrum Sensing in
V2X Networks* (v8, sole author **Davesh Vats**) — was prepared for submission
to the International Conference on Computing, Communication, and Technologies
(ICE2CT) 2026, but was **never presented or published**. No proceedings
version, DOI, or archival record of it exists anywhere. If you cite it, cite
it as an *unpublished manuscript* (this is exactly how the current Phase-1
manuscript in [`../`](../) cites it).

The author list on this manuscript is Davesh Vats (revision 2026-09-09).
The current Phase-1 manuscript — *The Price of Compliance* — supersedes this
work and should be used for any new citation or building-on.

## Editing and rebuilding

```bash
cd paper/legacy
tectonic v2x_paper_v8.tex     # or: pdflatex v2x_paper_v8.tex
```

The `.tex` file loads its images from `figures/` via `\graphicspath`, so the
directory is self-contained: edit `v2x_paper_v8.tex`, recompile, done.

## Changing the figures

All 7 figures are generated by `scripts/transferability_study.py` — the same
script, run in its original 3-seed configuration, produced the committed
PNGs:

```bash
cd paper/legacy/scripts
python transferability_study.py            # full protocol: seeds 42/123/456,
                                           # eps 0.01/0.03/0.05, 100 epochs
python transferability_study.py --quick    # smoke: seed 42, eps 0.03 only
```

Figures are written to `../figures/`; per-seed result JSONs go to
`transfer_data/` (runtime output, git-ignored). To restyle a figure, edit the
`generate_heatmaps()` / `generate_transfer_ratio_figure()` functions near the
bottom of the script (colormaps, annotations, dpi are all local constants).
Dependencies: `torch`, `numpy`, `matplotlib` — see the repository-root
[`requirements.txt`](../../../requirements.txt). CPU-only; the full protocol
takes a few hours on CPU.

## Honest record (read before reusing anything)

This manuscript is archived as-is, but it is **not** a reliable source of
final numbers by itself. The Phase-0 honesty audit (preserved under the
[`v2.0.0` release
tag](https://github.com/Daveshvats/v2x_adversarial_sensing/releases/tag/v2.0.0)
as `AUDIT.md`) found, among other things: a stale `code/` v1 pipeline in the
original zip, an unreconciled 58.2%-clean-accuracy official-AutoAttack run,
and a README architecture description matching neither the paper nor any
shipped code. The reproduction that *does* justify the paper's Table II/III/V
regime is `scripts/autoattack_eval.py` (v3) — also preserved under the
`v2.0.0` tag. The Phase-1 manuscript in [`../`](../) was written against
fully re-derived, audited numbers; use it instead.
