# paper/ — manuscripts, figures, and how to change them

Everything in this directory is regenerable from source. There are no
hand-drawn or screenshot figures: every figure is produced by a script in
[`scripts/`](../scripts/), and both manuscripts are plain-text LaTeX you can
edit with any editor.

## Current manuscript (Phase 1): "The Price of Compliance"

| File | What it is |
|---|---|
| `main.tex` | The manuscript source (Elsevier `elsarticle`, target journal: Vehicular Communications). Every number traces to a JSON in `../results/` — see the NUMBER POLICY comment at the top of the file and [`CLAIMS.md`](CLAIMS.md). |
| `main.pdf` | Compiled output of `main.tex`. |
| `CLAIMS.md` | Claim-by-claim verification matrix (VERIFIED / PENDING) mapping every paper claim to its result JSON. |
| `COVER_LETTER.md` | Submission cover letter. |

### Rebuild the PDF after editing `main.tex`

```bash
cd paper
tectonic main.tex        # or: pdflatex main.tex (run twice for cross-refs)
```

### Change a figure

| Figure (in `figs/`) | Regenerate with | Data source |
|---|---|---|
| `band_plan.pdf` + `band_plan.png` | `python scripts/band_plan_fig.py` | none — drawn from the band-plan constants that mirror `src/waveforms.py` (deterministic, seed 7) |
| `price_of_compliance.png` | `python scripts/run_plot.py` | merges `results/attack_results_{urban,highway,rural}_{untargeted,targeted_noise}.json` |
| `harm_chain.png` | `python scripts/harm_chain_fig.py` | `results/harm_chain.json` |

Workflow: edit the script (colors, labels, layout, or the underlying
constants) → run it → the file in `figs/` is overwritten → recompile the PDF.
`band_plan_fig.py` is fully deterministic, so an unmodified rerun reproduces
the committed figure byte-for-byte.
